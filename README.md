# cover-service

Генерація обкладинок для вертикальних відео. Витягує кадри в паузах мовлення,
відсіює технічний брак, фінальний вибір робить vision-модель, потім рендерить
за темплейтом aem college.

## Деплой на Railway

1. Заливаєш цю папку в приватний репозиторій на GitHub.
2. Railway → New Project → Deploy from GitHub repo → обираєш його.
3. Railway сам підхопить `Dockerfile`.
4. Variables:

```
ANTHROPIC_API_KEY = sk-ant-...
```

5. Settings → Networking → Generate Domain. Отримана адреса й піде в n8n.

Перевірка: `GET https://<адреса>/health` має віддати `{"ok": true, ...}`.

## Ендпоінти

### `POST /cover`
```json
{
  "file_id": "1UxaIQsciX2TRpV5coobx3TZj2KAJg4XJ",
  "text": "Житло в *Бангкоці*, за 330 доларів на тиждень.",
  "debug": false
}
```
Віддає JPEG 1080×1920.

- `text` порожній або відсутній → рендериться тільки кадр, без заголовка.
- `debug: true` → замість обкладинки віддає стрічку з трьох фіналістів,
  пронумерованих 1-2-3. Метрики лежать у заголовку відповіді `X-Cover-Meta`.
- Замість `file_id` можна передати `video_url`, якщо файл не на Drive.

### `POST /inspect`
Те саме тіло, але у відповідь приходить лише JSON з метриками всіх фіналістів.
Зручно, коли треба покрутити пороги й не дивитись на картинки.

## Текст і акценти

Заголовок береться з тіла запиту. Слово в зірочках рендериться
Medium Italic на 65% прозорості:

```
Житло в *Бангкоці*, за 330 доларів на тиждень.
```

Пунктуація після зірочок лишається базовим стилем, пробіл не додається.

## Шрифти

Кладеш файли в `fonts/` перед деплоєм:

```
fonts/HelveticaNeue-Regular.ttf
fonts/HelveticaNeue-MediumItalic.ttf
```

Або вказуєш свої шляхи через `FONT_REGULAR` та `FONT_ITALIC`.
Якщо курсиву немає, сервіс мовчки візьме Regular замість нього.

## Темплейт

| параметр | значення |
|---|---|
| кадр | 1080×1920 |
| шум | mono, комірка 3.9, чорний 25% |
| затемнення | чорний 15% на весь кадр |
| шрифт | Helvetica Neue Regular 98 |
| line height | 106 |
| letter spacing | −4% |
| колір | F0F0F0 |
| відступ зверху | 1125 |
| відступ зліва | 150 |
| ширина блоку | 780 |
| макс. рядків | 4, далі кегль падає 98 → 88 → 80 |

## Пороги (env)

| змінна | дефолт | що робить |
|---|---|---|
| `SILENCE_DB` | `-30` | поріг тиші в дБ |
| `SILENCE_MIN` | `0.25` | мінімальна пауза в секундах |
| `MAX_CANDIDATES` | `15` | скільки кадрів оцінювати |
| `ANTHROPIC_MODEL` | `claude-sonnet-5` | модель для фінального вибору |

Пороги відсіювання (моргання, відкритий рот, поворот голови, різкість,
капшнси) лежать константами вгорі `scoring.py`.

## Як воно вирішує

1. Качає відео у тимчасовий файл.
2. `silencedetect` дає тихі проміжки. Кадри беруться з їх середини, бо саме
   там Verba не малює субтитрів. Якщо пауз мало, додаються рівномірні таймкоди.
3. Кожен кандидат зменшується до 540px і проходить перевірку:
   різкість (Laplacian), очі (EAR), рот (MAR), поворот голови,
   щільність текстоподібних країв у нижній третині.
4. Кадри без жодного порушення сортуються за скорингом, топ-3 йдуть у модель.
   Якщо чистих немає взагалі, беруться найменш зіпсовані та `clean_frames: false`.
5. Переможець витягується в повній роздільній здатності й рендериться.

Якщо `ANTHROPIC_API_KEY` не заданий або модель відповіла помилкою, сервіс
мовчки бере перший кадр за скорингом. Пайплайн не падає.
